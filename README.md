# Right-Shulker-Box

Right-click any shulker box to open it instantly.<br>
No more pulling it out, placing it down, opening it, then putting it back.

**🔑 Key Features:**
- Instant Access: right-click a shulker box in your inventory, a chest, or most other inventories to open its contents right away
- Multiplayer Safe: multiple players can open the same shulker box at once and see each other's changes live, with no conflicts
- Duplication Protection: locks the shulker box's slot while it's open, blocks nesting one inside another, and refuses to open stacks larger than 1, built with duplication risk in mind from the start
- No Configuration Needed: just install and play
- Vanilla Clients Welcome: works with any unmodified client, no client-side mod, resource pack, or texture required

**❓ How It Works:**
1. Right-click a shulker box in an inventory screen.<br>
2. Its contents open in a familiar chest-style window instead of being picked up.<br>
3. Add or remove items, close it, and the shulker box stays right where it was.

**💯 Perfect For:**
- Inventory management and organization
- Players who lean on shulker boxes heavily for storage
- Anyone who wants fewer clicks between "I need one item" and "got it"

**⚙️ Installation:**
- Requires `Fabric Loader` and a matching `Fabric API` version, check the downloads page for supported Minecraft versions
- Install it on your server for multiplayer, vanilla clients work with it out of the box, nothing extra needed on their end!
- The mod also works client-side if you want to use it in a singleplayer or LAN world!

**❔ Frequently Asked Questions:**

Q: Do I need to install anything on the client?<br>
A: No. Any client can use it right away, modded or not. It only needs installing client-side for singleplayer or LAN, since your client runs its own server there too.

Q: Is this safe to use on a survival server?<br>
A: Yes. The shulker box's slot locks the moment it's opened, changes save to the real item instantly, and every open shulker box is re-checked once per tick to catch anything moved, removed, or tampered with.

Q: Can I put a shulker box inside another shulker box through this?<br>
A: No, same as vanilla.

Q: What happens if someone moves the shulker box while I have it open?<br>
A: Your view closes automatically. Nothing gets lost or duplicated.

Q: Does this work alongside other mods?<br>
A: It only adds a right-click action, nothing vanilla is replaced or removed, so it should coexist fine with most other mods.

Q: Which Minecraft versions are supported?<br>
A: Check the download page you got this from, new versions get added over time, so it isn't tied to a single one.
